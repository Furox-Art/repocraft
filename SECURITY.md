# Security Policy

## Reporting a vulnerability

Open a private security advisory through the repository's Security tab. Please
do not open a public issue for a suspected vulnerability.

## Supported versions

The latest release on the default branch receives security fixes. Older
releases are supported only at the maintainer's discretion.

## Scope

This policy covers the code in this repository. Report vulnerabilities in
third-party dependencies to their own maintainers.

Generated projects copy templates from this repository. A vulnerability in a
template is in scope here; a vulnerability in code a user writes inside a
generated project is not.
