# example-library

An example library generated by repocraft.

## Requirements

- Python 3.10 or newer.

## Installation

```bash
python -m pip install .
```

## Usage

```python
from example_library import add

print(add(2, 3))
```

## Development

```bash
python -m venv .venv
. .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"
python -m pytest
python -m ruff check .
python -m mypy
```

The test suite enforces 100% branch coverage, and CI rejects skipped tests
through the JUnit report gate. Pull requests run the same checks on every
supported Python version.
