# example-cli

An example command-line application generated by repocraft.

Repository: <https://github.com/example-owner/example-cli>.

## Requirements

- Python 3.10 or newer.

## Installation

```bash
python -m pip install .
```

## Usage

```bash
example-cli [NAME]
```

The command prints a greeting and exits with status `0`.

## Development

```bash
python -m venv .venv
. .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"
python -m pytest
python -m ruff check .
python -m mypy
```

The test suite enforces 100% branch coverage, and CI rejects skipped tests
through the JUnit report gate. Pull requests run the same checks on every
supported Python version.
