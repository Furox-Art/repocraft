# Security Policy

## Reporting a vulnerability

Open a private advisory at
<https://github.com/example-owner/example-cli/security/advisories/new>.

Please do not open a public issue for a suspected vulnerability.

## Supported versions

The latest release on the default branch receives security fixes. Older
releases are supported only at the maintainer's discretion.

## Scope

This policy covers the code in this repository. Report vulnerabilities in
third-party dependencies to their own maintainers.
